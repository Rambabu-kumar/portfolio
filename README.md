# BC Warrior — Rambabu Kumar's Portfolio

An English-language responsive portfolio built with plain HTML, CSS and JavaScript. It is designed for GitHub Pages and highlights verified project work without inventing employment history or credentials.

## Run locally

Open this folder in VS Code and use the Live Server extension to serve `index.html`. No build step or package installation is required.

## Personalize the assets

- Your home-page portrait is `assets/images/projects/rambabu bg remove imgae home.png`. Replace it there if you want to update your photo. If it is missing, the page displays a BC Warrior initials fallback.
- The About section portrait is `assets/images/projects/about image.png`.
- The My Sketches gallery displays the supplied images from `assets/images/sketches/` and each image opens at full size when selected.
- The supplied resume is available at `assets/files/Rambabu-Kumar-Resume.pdf`; the view and download buttons use this file.
- Education, experience, project implementation details, certifications, technical skills and languages on the page are based on the supplied resume. Private home-address details are intentionally not published.
- The EduCare project card uses the complete client screenshot you provided in a scrollable preview, with a link to open the full image. The BC Warrior Portfolio card uses a desktop screenshot captured from the local site at `assets/images/projects/portfolio-screenshot.png`.
- Programming instruction, ethical cybersecurity awareness, Zoom learning sessions, and the Babu Cyber Warrior channel are presented separately from development work.
- The supplied BC Warrior logo is used for the browser favicon and Apple touch icon.
- The skills section separates technologies demonstrated in the portfolio and EduCare project from fundamentals and learning-roadmap items; it does not assign proficiency scores or years of experience.

## Contact form

The form validates its fields in the browser and opens WhatsApp with a pre-filled message. It does not send or store messages; the visitor reviews and sends the message in WhatsApp. Resume view and download links use standard browser link behavior.

## GitHub Pages

The portfolio is published from the `main` branch at the repository root. Its GitHub Pages URL is [rambabu-kumar.github.io/portfolio](https://rambabu-kumar.github.io/portfolio/). To publish an update, push changes to `main` and confirm **Settings → Pages** uses the `main` branch and root folder.

The site uses relative asset paths and can also be published from a project subpath. External Google Fonts are optional; system font fallbacks are provided.
